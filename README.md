# Star Whisper Health (星语健康) · 小回的健康守护

> 原工程名: `mi_health`

让 AstrBot 通过小米运动健康**官方云端"亲友共享"接口**, 实时读取用户的步数、心率、血氧、睡眠、活力数据，提供女性生理期智能日历、历史趋势图表，并让小回在日常对话中了解你的身体状态、适时主动关怀。

**优势**:不用装 Gadgetbridge、不用换手机 App、不用 Termux 挂后台。小米运动健康继续正常用。

## 原理

底层依赖开源 SDK [`mi-fitness-python`](https://github.com/Misty02600/mi-fitness-python)。
通过一个**小米小号**添加大号为**亲友**并授权健康数据共享,服务器上用**小号的 token** 查询大号的数据。

```
小米手环 → 小米运动健康(大号) → 小米云端
                                    │  亲友共享
                                    ▼
                            mi-fitness-python(小号 token)
                                    │
                                    ▼
                            AstrBot 插件 mi_health
```

## 部署步骤

> 整个流程 = 【手机上做的事】+【服务器上做的事】+【AstrBot 面板填配置】
> 一次配好,以后一直用。

### 步骤一(手机上):准备两个小米账号 + 亲友授权

小米云端"亲友共享"接口的规则是**自己不能查自己**,必须由另一个账号(小号)作为"亲友"来查你(大号)的数据。所以要准备两个小米账号。

#### 1. 准备两个账号

- **大号**:你自己**正在用**的小米账号(手环连接的那个)
- **小号**:随便一个**没在用**的手机号注册一个新的小米账号(注册一个新号只要几分钟)

#### 2. 大号手机:允许被查看健康数据

在你**自己手机**的 **小米运动健康 App** 里:

1. 打开 App → 右下角"我的" → "设置" → "隐私设置" → "数据授权与管理"
2. 确认**运动数据、睡眠、心率**等都允许被亲友查看

#### 3. 小号手机(可以用另一台手机或模拟器):添加大号为亲友

1. 小号手机安装 **小米运动健康 App**,登录小号
2. App 里搜索"家人" / "亲友" / "关注" 功能(不同版本入口略有不同)
3. 用**大号的小米账号 ID / 手机号**添加为亲友,发送请求
4. 切回大号手机,同意亲友请求,勾选**允许对方查看步数 / 心率 / 睡眠 / 血氧**等全部数据

#### 4. 记下大号的 UID

大号手机:小米运动健康 App → "我的" → 点头像 → 里面能看到一串纯数字的 **小米 ID / 用户 ID**,这就是你的 `target_uid`,后面配置要填。

> 💡 UID 是纯数字,类似 `3254076555` 这样。不是"@xxx"那种昵称。

---

### 步骤二(服务器上):扫码登录,拿到 token.json

这一步是让**小号在服务器上留下一份登录凭证**(token.json),之后 AstrBot 就靠这个凭证去云端拉数据。

#### 1. 装依赖

在部署 AstrBot 的服务器上:

```bash
# 进入插件目录
cd data/plugins/mi_health

# 装依赖(会自动装上 mi-fitness SDK)
pip install -r requirements.txt
```

#### 2. 跑扫码登录脚本

```bash
# 克隆 SDK 仓库(里面带扫码登录的示例)
git clone https://github.com/Misty02600/mi-fitness-python.git
cd mi-fitness-python

# 跑登录脚本(具体文件名以仓库为准,一般叫 login_qr.py 或 examples/login.py)
python examples/login_qr.py
```

脚本跑起来后会生成一个二维码,可能是:

- 直接在终端里用字符画显示
- 或者保存成图片文件让你下载查看
- 或者起一个临时的 web 页面让你访问

#### 3. 用小号扫码

**关键:必须用「手机系统自带的相机」或「微信/浏览器」的扫一扫,千万不要用小米运动健康 App 里的扫一扫**(官方限制,会失败)。

- 用小号所在的那部手机扫这个二维码
- 手机上会跳出小米账号登录确认页,点"允许登录"
- 服务器终端会显示"登录成功",并在当前目录生成一个 **token.json** 文件

> ⚠️ 二维码有效期只有 **5 分钟**,超时要重跑
> ⚠️ 如果部署在国外 VPS 上,扫码可能因为网络问题失败,建议服务器地区选国内或香港

#### 4. 记下 token.json 的绝对路径

```bash
# 在服务器上跑一下,把绝对路径抄下来
pwd
ls -l token.json
```

假设显示 `/root/mi-fitness-python/token.json`,这个路径后面配置要填。

> 🔒 **安全建议**:`chmod 600 token.json` 限制只有你自己能读,防止别的进程偷。

---

### 步骤三(AstrBot 面板):填配置

AstrBot 管理面板 → 插件 → mi_health → 配置:

| 字段 | 填什么 |
|---|---|
| `token_path` | 步骤二拿到的 **token.json 绝对路径**,如 `/root/mi-fitness-python/token.json` |
| `target_uid` | 步骤一拿到的**大号 UID**(纯数字) |
| `auto_inject` | `true` 让 LLM 每次对话自动感知健康数据(推荐) |
| `cache_ttl` | 缓存秒数,默认 600(10 分钟),太小会频繁调云端 |
| `allowed_session_ids` | 隐私白名单,格式支持 `会话完整 ID` 或纯 `session_id`。留空 = 所有已启用会话都可查 |

填完保存,然后**在插件列表点"重新加载"**让配置生效。

### 步骤四:验证

在小回对话里发:

```
/health status     # 看 token 有没有过期
/health            # 查全部健康数据
/health steps      # 只看步数
/health sleep      # 只看昨晚睡眠
/health refresh    # 强制刷新缓存
```

## 使用方式

### 方式 A: 主动查询指令

- `/health` 查今日全部
- `/health steps` `/health hr` `/health sleep` `/health spo2`
- `/health refresh` 强制刷新
- `/health status` 状态检查

### 方式 B: 让 LLM 自动感知(推荐)

`auto_inject = true` 时,插件会在**每次对话**前把健康快照悄悄塞进 system_prompt。
小回会**作为背景常识**知道你今天走了多少步、心率如何、昨晚睡了多久,
但**不会主动罗列**,只在情境自然时被动引用(比如你说累/困/不舒服)。

### 方式 C: LLM Tool

小回也可以在需要时**主动调用** `get_user_health` 工具,比如你问"我今天走了多少步",她会自己去查。

### 方式 D: 后台主动关怀(v0.3+ 强化)

插件会**定时扫描**健康数据,发现异常时**主动开口**关心你——比如熬夜时心跳还很快、血氧偏低、白天步数太少、经期前后等场景。**不是每天定时打卡**,只有真的发生异常才会触发,冷却期内不重复。

#### 触发的异常类型

监测规则都可以在配置里单独开关:

| 规则 | 触发条件 | 默认 |
|---|---|---|
| 心率偏高 / 偏低 | 今日最高心率相对历史基线 z-score 超阈值 | 开 |
| 睡眠评分偏低 | 昨晚睡眠评分相对基线 z-score 低于阈值 | 开 |
| 血氧偏低 | 血氧低于绝对阈值(默认 93%) | 开 |
| 熬夜警告 | 到指定时刻(默认 23:30)心率仍高于平均值 | 关 |
| 步数偷懒 | 到指定时刻(默认 20:00)步数低于阈值 | 关 |
| 经期预告 | 距离预测经期日期 N 天内 | 开 |
| 经期中关怀 | 经期第 1-5 天,每 2 天一次 | 开 |
| 排卵期关怀 | 排卵日 ±2 天 | 关 |

#### hint 设计原则:纯数据陈述,不给结论

每条异常触发时,插件生成的 `hint` 是**纯客观数据陈述**,不带催促和判断,比如:

- ✅ "她今天最高心率 118 bpm, 比平时基线偏高"
- ✅ "她现在心率 92 bpm, 比平时平均值偏高"
- ❌ ~~"该睡啦"~~ ~~"一天都没怎么动"~~

**为什么这样设计**:让 LLM 结合上下文和人格自然发挥,不复读预设话术。你困了就说困,你在忙就说忙,不会被硬塞进一个"关心 = 催促"的模板里。

#### 关怀触达机制

**优先走"伪造消息注入"**:插件会通过 OneBot(aiocqhttp) 适配器**伪造一条你发给机器人的消息**(内容是异常场景的 Prompt 提示),让消息完整走一遍 AstrBot 的对话 Pipeline——这样:

- ✅ 走当前会话的**人格 / 世界书**设定
- ✅ 带上**最近的对话上下文**
- ✅ 回复**自动存入聊天记录**(下次对话能引用)
- ✅ 触发**其他插件的 Hook**(比如你自己的记忆插件)

**注入失败时兜底**:非 OneBot 平台(如企微、飞书)或注入异常时,自动降级为直发静态文案,不会漏推。

#### `bot_qq_id` 配置

伪造消息注入需要知道机器人的 QQ 号:

| 字段 | 说明 |
|---|---|
| `bot_qq_id` | **留空**:插件会自动从 CQHttp 实例的 `get_login_info()` 获取(推荐);**手动填**:适配器启动前就要用到时(比如刚启动就触发关怀),直接填机器人 QQ 号更稳 |

其余配置(检测冷却小时、允许推送时段、扫描间隔等)见配置面板每一项的 hint 说明。

## 隐私与安全

- `token.json` 是敏感凭证,VPS 上要 `chmod 600 token.json`
- 会话级隔离:如果某个会话把插件禁用了,LLM Hook / Tool 完全不生效
- 白名单机制:`allowed_session_ids` 可以限制只在你自己的私聊里能查
- 缓存兜底:云端调用失败时返回旧缓存,不打断对话

## 常见问题

**Q: token 过期了怎么办?**
A: **最省事的办法**: 进到 `data/plugins/mi_health/tools/` 目录, 双击 `刷新token.bat`, 用小号手机微信扫二维码, 新 token 会自动覆盖到配置的路径。然后去 AstrBot 面板点插件「重新加载」即可。

**Q: 数据延迟多少?**
A: 手环 → 小米云端本身有几秒~几分钟延迟,插件再加 10 分钟缓存。想更新鲜就调小 `cache_ttl` 或用 `/health refresh`。

**Q: 一定要小号吗?**
A: 是的。SDK 底层走的是"亲友共享"接口,自己不能查自己,所以必须有一个"亲友"关系。

## 🌸 前端页面 & 生理期日历(v0.4+ 新增)

除了聊天指令,插件还内置了一个**手机友好的 Web 前端**,可以在浏览器里像看 App 一样查看健康数据、记录生理期、查看历史趋势。

### 打开方式

插件启动后会在配置的端口(默认 `4847`)监听 HTTP 服务。首次访问需要带 Token:

```
http://<你的电脑局域网IP>:4847/?k=<Token>
```

Token 从两种地方拿:

- AstrBot 面板 → mi_health 配置 → `web_token` 字段
- 或者插件启动日志 `[mi_health.web] HTTP 服务已启动`(首次启动会自动生成 20 位随机 Token 并写回配置)

首次进入后,浏览器会自动把凭证写进 Cookie,**之后无论电脑还是手机再打开 `http://电脑IP:4847/` 都不用再输 Token**。可以在手机浏览器里"添加到主屏幕",当独立小 App 用。

### 页面功能

| 路径 | 功能 |
|---|---|
| `/` | **首页**:今日心率/血氧/步数/睡眠/活力,顶部有经期状态条,右上角一键刷新 |
| `/calendar` | **女性健康日历**:按月显示经期(实心粉)、预测经期(斜纹)、排卵日(紫)、排卵期(蓝);点日期可弹窗标记开始/结束、记流量、写备注 |
| `/history` | **历史趋势**:7 天 / 30 天切换,心率、血氧、步数、睡眠评分的折线柱状图 |

### 生理期功能

- **手动标记**:日历里点日期 → 弹窗 → "标记为经期开始 / 结束"
- **自动预测**:有 2 次以上历史记录后,插件会根据最近的经期数据自动计算平均周期和经期天数,并在日历上用斜纹粉预测下一次
- **排卵日**:根据下次经期倒推 14 天,用紫色标记,前后 5 天用蓝色标记为排卵期
- **主动关怀**:
  - **经期预告**:预测日期前 N 天温柔提醒一次(带片子)
  - **经期中关怀**:经期第 1-5 天每隔 2 天关心一次(不会每天,避免烦人)
  - **排卵期关怀**:默认关闭
  - **实现机制**:OneBot 平台通过伪造消息注入 AstrBot 事件流，由当前会话人格 + LLM 自然生成回复；其他平台或注入失败时走静态兜底文案直发

### 相关配置项

| 字段 | 默认 | 说明 |
|---|---|---|
| `web_enabled` | `true` | 前端服务总开关 |
| `web_host` | `0.0.0.0` | `0.0.0.0` 局域网可访问;`127.0.0.1` 仅本机 |
| `web_port` | `4847` | 监听端口 |
| `web_token_enabled` | `true` | 是否开启 Token 校验(强烈建议开) |
| `web_token` | 自动生成 | 首次启动自动生成 20 位随机 Token |
| `history_enabled` | `true` | 是否归档每次抓取的健康数据 |
| `history_keep_days` | `90` | 历史保留天数,超期自动清理 |
| `period_enabled` | `true` | 生理期功能总开关 |
| `period_default_cycle` | `28` | 首次无历史时的默认周期天数 |
| `period_default_length` | `5` | 首次无历史时的默认经期天数 |
| `period_incoming_care_enabled` | `true` | 经期预告关怀 |
| `period_care_enabled` | `true` | 经期中关怀 |
| `period_ovulation_care_enabled` | `false` | 排卵期关怀(默认关) |

其余细节(冷却小时、允许推送时段等)见配置面板每一项的说明。

### 安全建议

- **一定开 Token 校验**,否则同一局域网的任何人扫到端口就能看你的隐私数据
- 手机不要在公共 Wi-Fi 下打开这个链接
- 如果只想本机浏览器访问,把 `web_host` 改成 `127.0.0.1`,别人就完全访问不到

## 🔄 日常维护:token 过期怎么办

token 过期是最常见的问题（小米云端有效期不固定, 可能几个月也可能几周）。

**最省事**: 双击 `tools/刷新token.bat` → 小号手机微信扫码 → 完事。

具体流程:

1. 进到 `data/plugins/mi_health/tools/` 目录
2. 双击 `刷新token.bat`
3. 会自动使用 AstrBot 的 `.venv` 环境, 备份旧 token, 在终端里打印二维码
4. **用小号手机**的微信/系统相机扫码 (⚠️ 不能用小米运动健康 App 内的扫一扫)
5. 二维码 5 分钟内有效, 手机点"允许登录"
6. 新 token 自动覆盖到配置里的路径
7. 回 AstrBot 面板点 mi_health 插件「重新加载」

**怎么知道该刷新了?**

- 对话里发 `/health status`, 显示过期
- `/health` 系列指令报 401 / 未授权
- 插件日志里出现 `AuthError` 或 `token expired`
